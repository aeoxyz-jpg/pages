Privacy policy

Last updated: 2026-10-30

Who uses this app

mail-triage is a personal tool. Its only user is its owner and it only accesses Gmail accounts that belong to the owner.

What data it accesses

With the owner's authorization (Gmail scope gmail.modify), it reads message metadata (sender, subject, date, labels, snippet) and, for at most a few messages per run, the plain-text body.

What it does with the data

  • Classifies each new message as important, worth noting, or noise.
  • Adds a star to important messages and marks sorted messages as read. It makes no other change to the mailbox.
  • Writes a short summary into the owner's own private storage.

It never sends, drafts, forwards, deletes, archives, or moves email.

Sharing

Data is not sold, shared, or used for advertising. To classify messages, message metadata is sent to an AI model the owner uses under the owner's own account; nothing else leaves the owner's computer and private storage.

Storage and security

OAuth tokens are stored in the macOS Keychain on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

mail-triage's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
